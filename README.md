# portal_da_turma_Home
Trabalho do Porta da turma, o tema escolhido foi Home

## Elementos extras
### transition
- **O que é:** anima a mudança de uma propriedade CSS ao longo do tempo,
  em vez de trocá-la instantaneamente.
- **Como funciona:** `transition: 0.2s;` aplica 0.2s em todas as
  propriedades que mudam no `:hover`.
- **Por que escolhemos:** dá fluidez aos cards, o fundo, a sombra e o
  espaçamento entre letras mudam suavemente.

### text-shadow 

- **O que é:** adiciona sombra ao texto.
- **Como funciona:** `text-shadow: 1px 1px 2px;` cria uma sombra
  deslocada 1px à direita, 1px para baixo, com 2px de desfoque.
- **Por que escolhemos:** dá profundidade ao `<h1>` da hero, que está
  sobre fundo azul. Melhora a leitura do título.

### box-shadow 

- **O que é:** adiciona sombra ao redor de um elemento.
- **Como funciona:** `box-shadow: 0 2px 8px rgba(26, 26, 46, 0.08)`
  cria uma sombra 2px para baixo, 8px de desfoque e cor preta com
  8% de opacidade.
- **Por que escolhemos:** faz o card da figura parecer "flutuar"
  sobre a página, criando hierarquia visual sem precisar de bordas
  pesadas.
